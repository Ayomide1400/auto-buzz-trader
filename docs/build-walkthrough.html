How it got built — seven steps
01

Plan the guardrails before the code

Before writing anything, the plan fixed the boundaries: paper trading only, hard-pinned to Alpaca's paper API host; a $25–50 cap per trade; a 5-position ceiling; and a pause switch, since nothing would be standing by to click "stop."

02

Design the read/act loop

React + Vite dashboard on Vercel, talking to a handful of serverless functions that keep every credential server-side:

  • /api/trending — proxies Stocktwits' public trending endpoint
  • /api/account, /api/positions, /api/orders — live Alpaca state
  • /api/cron/trade-cycle — the actual buy/sell logic, triggered only by Vercel Cron
03

Make the bot only touch what it owns

Every order the bot places carries a buzz- tagged client_order_id. The sell rule and the activity log both key off that tag — so a pre-existing position already sitting in the account is never auto-sold, even if it stops trending.

04

Ship it — zero browser steps

With gh and vercel already authenticated, the whole path from empty folder to live URL ran through the CLI: repo created, project linked, secrets pushed as server-only environment variables, deployed to production.

05

Hit a real platform wall — and route around it

The pause flag was meant to live in Vercel Edge Config. Mid-build, that path hit a hard stop: this account's CLI session is SSO-authenticated, and Vercel blocks minting new personal API tokens from that kind of session.

Redirected, not blocked

The flag now lives in a small JSON file inside the repo, read and written live through the GitHub API — same instant, no-redeploy toggle, and every pause/resume is now also a timestamped commit.

06

Set the cadence — on purpose, not by default

Vercel's free Hobby plan caps cron jobs at once a day. Rather than quietly accept that or silently upgrade to a paid plan, the build shipped on the daily cadence — weekdays at 15:00 UTC, when the market is open — and flagged the tradeoff explicitly for a deliberate call on whether Pro-tier, more-frequent checks are worth it.

07

Prove it against the real paper account

Not "it built" — a real trade cycle, a real cap test, a real pause test. See below.

The one judgment call worth flagging
Cadence vs. cost

Checks the trending list once a day, not once an hour

A "trending" strategy is naturally intraday — but Vercel's free Hobby plan only allows one cron run per day. Shipping on Hobby, at 15:00 UTC on weekdays, was the deliberate default.

Upgrading to Vercel Pro ($20/mo) would unlock 15–60 minute checks. That's a cost decision, not an engineering one — so it stayed a flag, not a default.
